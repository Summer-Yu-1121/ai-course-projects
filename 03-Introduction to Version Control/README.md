# Introduction to Version Control

## Overview

This project demonstrates practical usage of Git and GitHub for version control, collaboration, and project management.

The objective was to learn how to manage source code using industry-standard Git workflows, including branching, committing, merging, and repository synchronization.

---

## Topics Covered

### Git Fundamentals

- Repository creation
- Local and remote repositories
- GitHub workflow
- Repository synchronization

### Branch Management

- Create branches
- Switch branches
- Documentation branch
- Refactoring branch

### Commit Workflow

- Stage changes
- Commit changes
- Commit message conventions

Examples:

```bash
git add .
git commit -m "doc: Improve documentation"
```

### Repository Maintenance

- .gitignore configuration
- Status monitoring
- Repository history

Examples:

```bash
git status
git log --oneline --all
```

### Merging Branches

- Merge documentation branch
- Merge refactoring branch
- Resolve conflicts
- Update remote repository

Examples:

```bash
git merge documentation
git merge refactoring
git push origin main
```

Through this project I learned:

- How to manage parallel development using branches
